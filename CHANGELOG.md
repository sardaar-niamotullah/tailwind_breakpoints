## 0.1.0

Initial Version of the library.

- Includes mobile-first breakpoint flags on `BuildContext` (`xs`, `sm`, `md`, `lg`, `xl`, `xxl`), following Tailwind CSS defaults with an added `xs` (480).
- Includes `screenSize`, `screenWidth` and `screenHeight` getters, plus the `minWidth`, `maxWidth` and `between` helpers, and an exported `Breakpoints` class with the default pixel values.
